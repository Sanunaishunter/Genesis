# 創世：天神模擬器

一個以瀏覽器執行的極簡「上帝模擬器」原型。開局時島上空無一物，玩家扮演天神，
能夠控制天氣、種下種子、創造動物與男女居民；接著居民會自行覓食、成長、繁衍與老去。

## 執行方式

不需要建置工具，直接開啟 `index.html` 即可遊玩，或以任意靜態伺服器啟動，例如：

```bash
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000
```

## 操作方式

1. 在右側面板選擇一項天神能力（天氣、種子、動物、男人、女人）。
2. 點擊島上的陸地施展該能力（天氣與時間流速按鈕點擊後立即生效，不需點擊地圖）。
3. 居民會依飢餓程度自動尋找果樹或動物覓食、成年後尋找配偶繁衍下一代，
   年老或長期挨餓則會死亡。
4. 天氣會影響植物生長速度與居民挨餓速度：降雨加速生長、乾旱使人更快挨餓、
   風暴有機率摧毀幼苗（甚至偶爾摧毀成樹）。

## 檔案結構

- `index.html`：版面與 UI
- `style.css`：介面樣式
- `js/game.js`：地形生成、天神能力、居民 AI 與畫面繪製的核心邏輯（純原生 JS，無外部相依）
